## Why these are in the repo

`.development/` is per-developer scratch — gitignored by design. The substantive research listed above is the kind of evidence-of-due-diligence an Authorize-step assessor would value seeing under [RMF Step 7](https://csrc.nist.gov/pubs/sp/800/37/r2/final) (Continuous Monitoring). Moving it here makes it part of the version-controlled audit trail.

## How this directory grows

When background research generates a substantive document that informs (or will inform) a compliance ticket, it lands here named `YYYY-MM-DD-<topic>.md`. The corresponding ticket discussion links back to it.
